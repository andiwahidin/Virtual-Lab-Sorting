# Lab Maya Algoritma Pencarian (Searching) & Pengurutan (Sorting)

Aplikasi web **Laboratorium Virtual (Lab Maya)** interaktif untuk mata pelajaran **Informatika SMA/MA/SMK Kelas X (Fase E) — Bab 2: Algoritma dan Struktur Data**, berdasarkan buku teks resmi *Informatika untuk SMA/MA/SMK/MAK Kelas X (Edisi Revisi)* halaman 80–89.

## Fitur Utama

1. **Splash Screen Visual & Animasi Loading**: Menampilkan perbandingan inti *Bubble Sort*, *Insertion Sort*, dan *Selection Sort* pada deret uji `[2, 3, 7, 6, 5]` serta mengaktifkan synthesizer **Web Audio API**.
2. **Materi & Teori Visual Interaktif**:
   - **Pencarian (*Searching*)**: 3 elemen formal masalah pencarian (sekumpulan objek, kriteria pencarian, pengecekan kriteria) serta perbandingan strategi pencarian.
   - **Pengurutan (*Sorting*)**: Dua langkah utama (*pembandingan* dan *penempatan/pertukaran*) serta telusur lengkap **Bubble Sort**, **Insertion Sort**, dan **Selection Sort**.
3. **Simulator Interaktif & 5 Misi Praktikum**:
   - Mode eksekusi per langkah (*Step-by-Step*), *Auto Play* dengan pengatur kecepatan, serta **Mode Pertukaran Manual** (klik langsung 2 elemen).
   - Tabel hidup **Bagian Terurut | Bagian Belum Terurut | Nilai Terkecil** untuk *Selection Sort*.
   - **Tabel Data Hasil Percobaan** yang otomatis terhubung ke laporan PDF.
4. **LKPD Digital 10 Soal & Ekspor PDF A4 (`jsPDF 2.5.1`)**:
   - Bagian A (Analisis Data 1–4), Bagian B (Diagnostik Otomatis 5–8 dengan tombol **Cek**), dan Bagian C (Penalaran HOTS & Kesimpulan 9–10).

## Cara Publikasi ke GitHub Pages / Netlify

1. Simpan berkas `index.html`, `style.css`, `script.js`, dan `README.md` di dalam satu repositori/folder.
2. Letakkan foto profil pengembang dengan nama berkas `profil.jpg` di folder yang sama (apabila belum ada, halaman Pengembang otomatis menampilkan avatar SVG default).
3. Unggah ke repositori GitHub dan aktifkan **Settings > Pages**, atau tarik folder langsung ke **Netlify Drop**.
